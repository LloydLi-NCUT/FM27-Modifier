# FM27 修改器

[下载 v0.1.0](https://github.com/LloydLi-NCUT/FM27-Modifier/releases/tag/v0.1.0)

适用于 Windows 和 Steam FM27 Build 26340721。

1. 解压全部文件，保持目录结构不变。
2. 启动游戏并载入存档，再打开 `FM27修改器.exe`，点击“连接”。
3. 比赛功能需先进入比赛，点击“记录比赛”，回到游戏运行几秒后暂停，再设置并开启功能。停止或调整功能前请先暂停比赛。
4. 关闭功能后再退出修改器或离开比赛。建议使用前备份存档。

当前可用：本队基础比赛属性、比赛体能、全队体能恢复、身高倍率；部分执教功能可使用。界面中未启用的项目暂不可用。身体倍率支持 0–1。
