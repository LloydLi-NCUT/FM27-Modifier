# FM27 修改器 v0.1.1

适用于 Windows 64 位、Steam 版 FM27（构建 26577676）。解压后可直接运行。

1. 启动 FM27 并载入存档。
2. 打开 FM27-Modifier.exe，点击「连接 FM27」。
3. 设好参数，再勾选要用的功能。

调整比赛属性倍率或伤病类型前，先关闭对应功能。速度、爆发力、平衡和耐力最高按游戏原版满值计算。
